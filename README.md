# 🧠 Deep Learning in Computer Vision Models

Welcome to the **Deep Learning in Computer Vision Models** repository — a curated collection of classic and modern machine learning models implemented for tasks such as image classification, segmentation, and text classification. This repo showcases practical applications of fundamental algorithms and is designed to serve both educational and experimental purposes.

---

## 📁 Repository Contents

| File | Description |
|------|-------------|
| `Image_Classification_using_KNN.ipynb` | Implements a K-Nearest Neighbors (KNN) classifier for image classification using handcrafted features. |
| `Naïve_Bayes_Classifier_for_Color_Image_Classification.ipynb` | Applies Naïve Bayes to classify color images by converting pixel distributions into probabilistic features. |
| `Naïve_Bayes_Classifier_for_Text_Classification.ipynb` | Implements a Naïve Bayes model for text classification using bag-of-words features and Laplace smoothing. |
| `Image_Segmentation_using_K_Means.ipynb` | Uses K-Means clustering to perform unsupervised image segmentation, separating regions based on color features. |
| `EM_Algorithm_for_Image_Segmentation.ipynb` | Applies the Expectation-Maximization (EM) algorithm to achieve probabilistic segmentation of image pixels. |

---

## 🔍 Model Overviews

### 1. K-Nearest Neighbors (KNN) – *Image Classification*
- Feature extraction via pixel/region statistics
- Distance-based classification
- Simple yet effective baseline for visual pattern recognition

### 2. Naïve Bayes – *Color Image & Text Classification*
- Gaussian Naïve Bayes for image data (RGB distributions)
- Multinomial Naïve Bayes for text classification
- Focused on probabilistic learning from independent feature assumptions

### 3. K-Means Clustering – *Image Segmentation*
- Clusters pixels based on color features (e.g. RGB)
- Reconstructs segmented images by labeling regions
- Fast and effective for unsupervised partitioning

### 4. Expectation-Maximization (EM) – *Image Segmentation*
- Unsupervised pixel labeling via probabilistic latent variable models
- Soft clustering alternative to K-Means
- Suitable for images with overlapping region statistics
